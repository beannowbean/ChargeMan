# Charge Man Prototype
충전을 기반으로 하는 2D 탑뷰 플랫포머 보스러쉬 퍼즐게임

## 실행 안내
- **실행이 안될 시**:
  1. Unity 상단 메뉴에서 `Edit` → `Project Settings` → `Player`
  2. 아래로 스크롤하여 **Active Input Handling** 옵션을 **Both**로 변경

---

## 맵(Map)
- **16 × 16** 타일 적용
- **Border line** 적용

---

## 플레이어(Player)
- **이동**: 방향키  
- **대시**: 방향키 + `Shift`  
- **차지(Charge)**: `X` 키  
- **근접 공격**: `Z` 키
- **애니메이션**
  - Stand 애니메이션
  - Charge 애니메이션
  - Attack 애니메이션

---

## 보스(Boss)
- Stand 애니메이션 구현
